# 01 - Host Discovery

## Objective

Learn how Nmap checks whether a host is alive and understand the difference between `localhost`, `127.0.0.1`, and a private IP address.

---

## Important Terms

### Nmap

Nmap (Network Mapper) is an open-source tool used to discover hosts and gather information about devices on a network.

### Reconnaissance

Reconnaissance is the process of collecting information about a target before performing further actions.

### Host

A host is any device connected to a network, such as a computer, server, or virtual machine.

### Host Discovery

Host Discovery checks whether a device is alive and responding on the network.

### Hostname

A hostname is the name assigned to a device on a network.

Example:

```text
ubuntu-vm
```

### localhost

`localhost` is a hostname that always refers to the computer you are currently using.

### Loopback Address

`127.0.0.1` is the loopback IP address used for communication with the same computer.

### Private IP Address

A private IP address identifies a device within a local network and is not directly accessible from the internet.

### Port

A port is a communication endpoint that allows network services to send and receive data.

### Service

A service is a program that listens on a port and responds to network requests.
