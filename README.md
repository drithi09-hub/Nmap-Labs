## Lab Environment

- Operating System: Ubuntu Linux (Virtual Machine)
- Tool: Nmap

## Labs

- 01 - Host Discovery
- 02 - Port Scanning 
- 03 - Service Enumeration 
- 04 - OS Detection 
- 05 - Network Assessment 

## Learning Goals

- Discover live hosts
- Identify open ports
- Understand running services
- Perform basic network assessments
