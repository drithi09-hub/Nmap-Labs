# Service Enumeration

## Objective

Learn how to identify the services, software, and versions running on open ports using Nmap.

## Important Terms

### Service Enumeration
The process of identifying the services running on open ports.

### Service
A function provided over the network, such as HTTP, SSH, or FTP.

### Software
The application that provides the service, such as Apache, OpenSSH, or CUPS.

### Version Detection
The process of identifying the version of the software running on a service.

### Banner
Information returned by a service that may include its software name and version.
